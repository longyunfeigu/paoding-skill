# walkthrough.packet
**Page job:** 读者跟着我（agent）走完乔布斯 skill 的六站，每站看到难点、先猜、再看机制原文。
**Reader state:** 已读 overview，认识全景图。
**Voice:** 第一人称执行体；预测点和练习用「你」。
**Page-specific standard:** 七步骨架完整；机制小节必须有引用块；每站面包屑用同一条链。
**Evidence shape:** 源 SKILL.md 原文引用、目录树、检查点表格样例。
**Failure mode:** 变成 Phase 清单复述。
**Pain scan rows used:** 全部 stage 相关行。
**Inputs:** brief 的 stage IDs + 机制线。
**Must include:** 开头放 main-flow 全景；交接句首尾相扣。
**Must avoid:** 「我作为 AI」；发明 brief 没有的痛点。
**Packet output:** content/walkthrough.md
**Self-check:** stage-writing.md 自检清单。
