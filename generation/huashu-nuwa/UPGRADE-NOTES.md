# 新旧手册对照 — 旧版协议（v1）vs 本手册（v2）

同一个源 skill，两版拆解协议的产物对照。本目录即 v2；v1 手册已从仓库移除（仅留此对照记录）。

## 协议升级直接看得见的差异

| 维度 | v1 | v2 |
| --- | --- | --- |
| 基线声明 | 无（全文 0 处） | meta 必填，Overview 渲染为专门区块；所有难点断言锚定基线 |
| 难点写法 | 每站一个扁平 `painPoint` 字符串，无分类无证据 | 每站两问（领域难点/行为难点），证据四级标注，「确无」必须显式写 |

## 协议升级带来的新内容（v1 没有的发现）

1. **「DNA 而非金句」被升格为表征解法卡（A1）**：v1 把它写在 overview 叙事里；v2 把它固化为
   「中间产物形态决定泛化能力」的可迁移模式，并连到 A2（筛选标准）形成认知难点的完整链条。
2. **数据流章回答了 v1 的 File Map 不问的问题**：research/ 与结论分离是为了让判断可审计；
   sources/ 单独存在是为了让一手/二手的边界落在文件系统层面——这些「为什么长这样」在 v1 是空白。
3. **A9 黑名单的不对称设计**（英文无黑名单、中文点名到平台）被识别为平台伤疤并给出迁移边界——
   v1 的 pattern 结构会把它和真正可迁移的招混在一起。
4. **盲区清单**给了源 skill 作者四条可执行的改进项（见 apply-it「作者」列），v1 没有这个产物。
