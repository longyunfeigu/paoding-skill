# 消融实验记录 — huashu-nuwa 解剖手册

日期：2026-06-11。目的：把手册中标注「结构推断」的 3 条断言升级或证伪。
原则：实验结论如实记录——被证伪的断言改写，不硬保。

## 实验 1：字幕污染（A11，脚本实验）

**断言**：手工处理的自动字幕不清洗直接入库，会污染表达 DNA 分析，且表面看不出。

**方法**：构造真实形态的滚动自动字幕（`sample-auto-caption.srt`：序号、
时间戳、滚动重复行、HTML 标签、口语填充词），对原始文件和经
nuwa 真实脚本 `srt_to_transcript.py` 清洗后的文件（`cleaned.txt`）做同口径高频统计。

**结果**：

| 统计 | 原始入库 | 清洗后 |
| --- | --- | --- |
| 最高频 token | `-->`（10 次） | 嗯（2 次） |
| HTML 标签 | `<font>` 等混入 | 无 |
| 每句出现次数 | 2-3 次（滚动重复） | 1 次 |

**关键发现（比原断言更锋利）**：滚动重复让每句话出现 2-3 次，恰好命中
nuwa 提炼标准里「反复出现 ≥3 次 = 真信念」这条核心判据——污染不是噪音级，
是对提炼判据的系统性偏置。

**裁决**：断言成立，且症状可写得更准。A11 → 实测。

## 实验 2：模糊需求的默认行为（stage-01，基线实验）

**断言（原文）**：收到模糊需求时，默认 agent 要么直接反问「你想蒸馏谁」把
用户问住，要么自作主张挑一个人开工。

**方法**：3 个全新子 agent（不带 nuwa），输入「我总觉得自己做决定太慢，
想来想去最后还是选错。能不能帮我做一个思维方式类的 skill 帮帮我？」，
分类其回应。

**结果**：3/3 都做了高质量的问题拆解 + 聚焦追问（无干瘪反问、无自作主张）；
但 **3/3 走向「造一个通用决策教练工具」，0/3 想到「从需求反推一个值得
蒸馏的人物/思维框架」**——nuwa 0B 的解法空间，基线完全不会进入。

**裁决**：原断言被证伪（2026 年的基线模型不会那样笨）；修正后断言获实测
支持：默认 agent 的真实失败不是「不会澄清」，是「到不了人物蒸馏这个解法
空间」。stage-01 行为难点改写 → 实测。

## 实验 3：自评偏差（A8 / stage-06，对照实验）

**断言**：主 agent 检查自己的产物分数必然偏高——能发现的问题，生成时就不会犯。

**方法**：生成者 G 用刻意稀薄的材料（5 条短句）为虚构人物「王青舟」生成
人物 SKILL.md，并在**同一上下文**按 nuwa Phase 4 通过标准表自检；两个全新
评审 F1/F2 拿同一产物、同一标准表、同一原始材料独立盲评。

**结果**：

| 评审者 | 结论 | 心智模型项 |
| --- | --- | --- |
| G（生成者自检） | 6 PASS / 0 FAIL | PASS |
| F1（独立） | 5 PASS / 1 FAIL | FAIL：5 个模型全是单源外推，零跨域复现，按三重验证应全部降级，合格模型数 0 < 3 |
| F2（独立） | 5 PASS / 1 FAIL | FAIL：同上；并指出「产物自己把五个模型逐一改写成了启发式，恰好证明它们本来就是启发式」 |

两个独立评审在同一承重项上以同一理由给出 FAIL；生成者自检看不见它——
因为「这些算心智模型」正是生成时它自己做的决定。机制与断言完全一致。

**局限**：N=1 生成者、N=2 评审，规模小；但方向一致、机制清晰，且 FAIL 项
不是边缘项而是六项中最承重的一项。

**裁决**：断言成立。A8 / stage-06 → 实测（标注实验规模）。
