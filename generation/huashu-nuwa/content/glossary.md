### 心智模型
**定义:** 一个人看世界的镜片，能用来推断他对没讨论过的新问题的立场。
**例:** 纳瓦尔的「杠杆」——在财富、成长、职业选择三个域复现，且能推断他对没谈过的新问题（如远程办公）会怎么看。
**它在哪个 stage 出现:** stage-05 提炼的核心产物，stage-06 填进模板
**它解决什么问题:** 防止人设只会复述旧观点（金句没有生成力）
**我怎么用它:** 每个模型记录名称、一句话描述、≥2 个场景的来源证据、应用方式、局限
**容易误解:** 不是「他说过的重要的话」——必须过三重验证；高频金句往往只是表达 DNA

### 决策启发式
**定义:** 此人做判断的快速规则，能写成「如果 X 则 Y」并有案例支撑。
**例:** 乔布斯：「如果要做市场调研，就已经输了」——具体场景的判断规则，带案例，但没有跨域复现到心智模型那一级。
**它在哪个 stage 出现:** stage-05（三重验证只过 1-2 重的候选降级到这里）
**它解决什么问题:** 给不够格当模型但真实存在的判断规则一个去处，避免硬塞或硬删
**我怎么用它:** 5-10 条，每条带场景和案例
**容易误解:** 不是模型的次品——它是「具体场景的规则」，模型是「跨域的镜片」，层级不同

### 表达 DNA
**定义:** 此人说话的可量化指纹：句式偏好、高频词、节奏、幽默方式、确定性表达。
**例:** 对 20 个真实段落做统计：类比密度（每段几个类比）、转折频率（"但是"出现率）、确定性用语（"绝对/也许"之比）——量化出来的指纹，不是印象。
**它在哪个 stage 出现:** Agent 3 取证（stage-03），stage-05 的 2.3 节分析，stage-06 转成风格规则
**它解决什么问题:** 防止生成的 skill 说话像通用 ChatGPT（风格测试不通过）
**我怎么用它:** 转为角色扮演规则；口癖适度使用——「太多变成模仿秀」
**容易误解:** 表达 DNA 管「怎么说」，心智模型管「怎么想」——只有 DNA 没有模型，就是开场那个金句人设

### 三重验证
**定义:** 候选论点升级为心智模型的三道筛：跨域复现（≥2 个领域出现）、有生成力（能推断新立场）、有排他性（不是人人都这么想）。
**例:** 「杠杆」过三重：财富/职业/学习三域都出现 ✓、能推断对新问题的立场 ✓、并非人人把它当第一原则 ✓ → 升级为模型；「专注很重要」只过跨域一重 → 降级为启发式都勉强。
**它在哪个 stage 出现:** stage-05，方法论住在 extraction-framework.md
**它解决什么问题:** 随口一说和真信念在单条材料里无法区分
**我怎么用它:** 三重全过 = 模型；1-2 重 = 降级为启发式；0 重 = 不纳入
**容易误解:** 不是数出现次数——高频不等于跨域，口癖出现一百次也过不了排他性

### 诚实边界
**定义:** skill 必须明确写出的「我做不到什么」：不能预测全新问题的反应、公开表达与真实想法可能有差、信息截止日期。
**例:** 「05 决策维度只找到 2 条可用来源，本节判断置信度低」——具体到维度和条数，而不是一句「仅供参考」。
**它在哪个 stage 出现:** stage-05 的 2.6 节产出，stage-06 是模板必备 section，验证要求至少 3 条具体局限
**它解决什么问题:** 信息不足时强行写满 = 编造（60 分诚实 > 90 分编造）
**我怎么用它:** 信息越少这一节越长；冷门人物每个模型标注「基于有限信息推测」
**容易误解:** 不是免责声明——「仅供参考」不算，「05 决策维度只找到 2 条可用来源」才算

### Agentic Protocol
**定义:** 写进生成的人物 skill 里的回答工作流：先分类问题（要事实/纯框架/混合），需要事实的必须先用工具研究再回答，研究维度从此人的心智模型推导。
**例:** 问芒格 Vision Pro 值不值得做 → 协议判定"要事实" → 先查激励结构与单位经济（维度来自他的模型），查完才答；不是通用的「搜索相关信息」。
**它在哪个 stage 出现:** stage-06 构建时生成，是模板里唯一「按人定制生成」而非填空的段落
**它解决什么问题:** 人设「说得像」但遇到事实问题凭训练语料编造（开场的 Vision Pro 失败）
**我怎么用它:** 芒格查激励结构、塔勒布查尾部风险——维度必须来自模型，不能是通用的「搜索相关信息」
**容易误解:** 不是给女娲自己用的——它是女娲写进产物里的，让生成的 skill 在运行时也先做功课
