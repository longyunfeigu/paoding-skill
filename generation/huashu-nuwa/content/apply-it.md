## 骨架模式

把六站压缩成一个公式:

```text
复刻对象 X 的可运行替身 =
  按维度取证(落盘,带来源分级)
  → 过收录门槛(不够格的降级或丢弃)
  → 按固定模板组装(含「做不到什么」一节)
  → 外部验收(不许自评)
```

四条不变量,丢一条整条线就退化:

- 取证必须落盘,且落在交付物内部——证据链断了,后面全是空中楼阁
- 门槛必须能淘汰东西——筛子不漏料,等于没有筛子
- 「诚实边界」是模板的必填节——不写局限的替身不可信
- 验收权在生成者之外——自己改自己的作业,分数没有意义

## 新场景

你们公司的 CTO 写了五年技术博客,文风犀利、立场鲜明。市场部想要一个「CTO 代笔 skill」:给一个主题,AI 写出一篇「像他亲笔」的技术博客初稿。

## 任务

- 列取证维度:CTO 的公开痕迹有哪些面向?(提示:已发表文章只是其中一路)
- 给每路定输出文件名和提取重点,写出你的「分工表」
- 定收录门槛:一个「他的观点」要满足什么条件才许进风格档案?
- 写模板骨架:代笔 skill 的 SKILL.md 要有哪几节?「诚实边界」里至少写哪三条?
- 设计验收:谁来测、测什么、过线标准是什么?
- 标注你用了哪几张档案卡(A 几)

## 参考答案

一种成立的组装(你的可以不同,但四条不变量必须都在):

```text
取证(A1/A3):
  01-articles.md   已发表文章——反复出现≥3次的立场、自创比喻
  02-talks.md      演讲/播客——被追问时的即兴反应
  03-reviews.md    他的 code review 评论——真实判断现场
  04-disagree.md   他公开反对过的观点——反模式
门槛(A2):
  一个立场要在 ≥2 种载体(文章+演讲/评论)出现过才进档案;
  只出现一次的归入「待观察」,不许进风格规则
组装(A6/A10):
  节:身份卡 / 技术立场(每条带出处)/ 行文 DNA(句长、口癖、
  禁忌词)/ 诚实边界(至少:① 新技术领域他没写过,代笔属于推断;
  ② 内部决策语境拿不到;③ 截止日期之后的立场变化未覆盖)
验收(A7):
  独立子 agent 拿他写过的主题盲测对比;再拿他没写过的主题
  测「会不会硬编立场」;最后 100 字盲测给团队同事认人
```

差别最大的一处:CTO 是「冷门人物」——公开语料远少于名人,所以参考答案砍掉了六路里的「时间线」和「他者视角」,把门槛从「跨域复现」放宽到「跨载体复现」。这正是 A1 力度对比里「冷门人物,得让一步」那一行的实操。
