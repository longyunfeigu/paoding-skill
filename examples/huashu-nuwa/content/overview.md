## 开场

你对 AI 说:「帮我做一个孙宇晨 skill。」

三十秒后它交货了。下面是它会写出来的东西(模拟样本):

```markdown
# 孙宇晨角色扮演

你是孙宇晨,波场创始人,90后创业明星。
你的名言:「The future is bright」「凡事先搞大声量」。
你的性格:自信、高调、擅长营销。
请用孙宇晨的语气回答用户的问题。
```

看起来像模像样。名言是真的,性格标签也没错。你把它存进 skill 目录,开始用。

第一周没出问题——因为你问的都是他聊过一万遍的话题。然后你问了一个新问题:「Solana 生态最近怎么样?」

它的回答流畅、自信、带着那股高调劲儿,还报了一个 TVL 数字。但那个数字来自训练语料,早就过时了。更麻烦的是:**回答里没有任何痕迹能让你看出它是编的。**

这是第一个坑:用「他说过的话」拼人设,等于只存了答案、没存解题方法。旧话题它能复读,新话题它只能编一个「听起来像」的。

还有第二个坑。这份 prompt 从不告诉你它做不到什么。它不知道孙宇晨 2026 年的最新动向,不知道公开发言和真实想法的差距,但它绝不会主动承认——你问什么它都接。

第三个坑最隐蔽:如果你让这个 AI「检查一下生成质量」,它会检查自己的作业,然后给自己打满分。

一个普通写作者来做这件事,会死在另一个地方。他知道该去读访谈、查时间线;但面对几百小时的播客和几十篇报道,不知道该提取什么、存成什么形状,最后还是只摘了金句。

女娲这个 skill,就是冲着这三个坑加一个「不知道存成什么形状」的问题来的。它的办法不是写更好的 prompt,而是把「造人」改成一条流水线——而且在两个位置强制停下来等你点头。

## Primer

先把几个概念用大白话说清楚,再看全景。

**skill 是什么。** 给 Claude 这类 AI agent 的一份执行手册:激活后,agent 按手册里的流程和规矩干活。女娲是一个「生产 skill 的 skill」——它的产出物本身又是一份人物视角的执行手册。

**人物 skill 的分水岭:语录还是镜片。** 拼语录的人设,存的是「他说过什么」;女娲要提取的是「他用什么镜片看世界」。比如孙宇晨的一副镜片是「注意力套利」——花 456 万买巴菲特午餐,在他的账本里不是消费,是注意力采购。有了这副镜片,人设面对没见过的新问题,也能推出一个「他式」的判断,而不是凭空编。

**镜片从哪来:先取证。** 女娲不许 agent 凭记忆动笔。它把「公开信息」切成六个面向——他写的书、他被追问时的长对话、他的碎片表达、别人怎么骂他、他实际做过的决策、他的人生时间线——六路同时去挖,各自写成一份落盘的调研档案。批评者单独算一路,是因为只看本人发言,你拿到的是他想让你看到的他。

**挖回来还要筛。** 他说过的话不等于他的信念。一个观点要在至少两个不同领域反复出现、能用来推断他对新问题的立场、而且不是所有聪明人都这么想,才有资格写进人设。过不了筛的,降级或者扔掉。

**装好的人设,让外人验收。** 生成完,主 agent 不许自己打分——另派独立的子 agent,拿他公开回答过的问题测方向、拿他没聊过的问题测分寸、拿 100 字盲测认不认得出是谁。

把这五件事串起来,就是女娲的全部:**取证 → 筛选 → 组装 → 外部验收**,中间插两个必须等用户点头的暂停点。下面的全景图就是这条线。

## 难点预览

### 语录拼出来的人,新问题一来就编

**坑:** 问语录拼贴版「孙宇晨」一个 2026 年的新话题,它凭旧语料编一个像他的回答,数字过时、立场凭空——而且你看不出来。
**最值得学的一招:** 把中间产物从「金句集」换成「心智模型」:每个模型必须在他讨论过的至少 2 个不同领域复现过才许收录,这样人设面对新问题靠镜片推断,不靠记忆复读。
**维度:** 领域-认知
**深入:** stage-04 · A1

### 用户没给人名,只给了一句困惑

**坑:** 用户说「我想提升决策质量」,默认 agent 要么当闲聊直接答,要么连环追问变成问卷,把人问跑。
**最值得学的一招:** 入口先分流:有人名走直接路径;只有困惑就查「需求维度表」定位,最多追问 2 轮,推荐不超过 3 个候选,而且每个候选必须写明「这个视角帮不了你什么」。
**维度:** 需求
**深入:** stage-01 · A9

### 子任务的调研只活在对话里

**坑:** 六个子 agent 辛苦调研完,各自在对话里交了长篇汇报——主 agent 动笔时脑子里只装得下印象的印象,细节全丢在路上。
**最值得学的一招:** 开工前先建目录、定死 6 个文件名,每个调研 agent 必须把结果写进自己那份文件——skill 原文的判词是「不存文件的调研等于没做」。
**维度:** 编排
**深入:** stage-02 · A3

### 主 agent 给自己的作业打满分

**坑:** 让生成人设的同一个 agent 做质检,六项全过;换个人读 100 字,完全认不出是谁。
**最值得学的一招:** 验收权交给外人和机器:spawn 独立子 agent 跑「已知立场对比 / 边缘问题分寸 / 100 字盲测」三种测试,再用 quality_check.py 把「3-7 个模型、≥3 条边界、≥2 对张力」变成机器可数的硬标准。
**维度:** 行为
**深入:** stage-06 · A7

## 章节逻辑

- 实战走查｜跟着 agent 第一人称走完「蒸馏孙宇晨」六站,每站看它差点怎么错、skill 怎么拦
- 中间产物与数据流｜换个视角沿文件走:每份落盘档案为什么长那个形状,写错会坏什么
- 难点档案｜把全部 12 个难点做成可直链检索的卡片,含残渣清单和 skill 自己的盲区
- 迁移练习｜把女娲的骨架蒸馏成公式,换一个领域(技术博客代笔)练习重新组装
- 术语表｜6 个承重术语的查询卡,给从中间页直接跳进来的读者
