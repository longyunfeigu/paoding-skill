# apply-it.packet

**Page job:** 读者拿一个新场景（40 期播客转图文精华帖）练习挑卡、拼骨架；参考答案折叠在后。
**Reader state:** 读完档案，知道 A1~A13 的编号含义。
**Voice:** 出题人，不是总结者。
**Page-specific standard:** 骨架模式是组合层（公式＋不变量），不重列卡片；任务让读者产出（清单、映射表、流水线、入口骨架）；参考答案在练习之后。
**Evidence shape:** 卡片映射表、流水线 ASCII、入口文件骨架代码块。
**Failure mode:** 励志总结；参考答案直接代替练习。
**Pain scan rows used:** 仅消费可迁移性=高 的卡（A1~A8、A10~A12）。
**Inputs:** archive 高迁移卡；brief 骨架（内容定稿→一次对齐→锚点验收→受控批量→单源交付）。
**Must include:** 「60% 直接抄能用吗」这类逼读者改造而非照搬的问题。
**Must avoid:** 新场景与视频太近（必须换域）。
**Packet output:** content/apply-it.md。
**Self-check:** 下一步分「作者」「偷招的人」两份，作者项来自盲区/残渣。
