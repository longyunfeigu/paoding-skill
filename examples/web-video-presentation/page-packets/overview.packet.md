# overview.packet

**Page job:** 让没见过源 skill 的读者带着「做网页 ≠ 做能录屏的网页」这条沟和全景图离开本页。
**Reader state:** 知道什么是 AI agent 和网页，不知道什么是录屏视频网页、step、token。
**Voice:** 大白话讲失败现场，先坑后名词；不夸 skill。
**Page-specific standard:** 开场只用读者语言（录屏、滚动、对不上嘴），不出现 narrations.ts / outline 等源包词；基线一句话在 meta frontmatter。
**Evidence shape:** wow-compare SVG 对照图；预览卡 5 张（维度异质：领域-认知 ×2、品味、编排、领域-工程）。
**Failure mode:** 目录式摘要、抽象夸奖、开场就甩源包术语。
**Pain scan rows used:** 真相源 / outline 留白 / AI 腔 / 并行一致 / 动画≤口播 五行进预览卡；响应式直觉行进开场（工程师基线）。
**Inputs:** brief 的 pain scan 表、贯穿例子、theme.json 真实数据（midnight-press bestFor）。
**Must include:** 开场失败场景 6+ 块、Primer 8 拍、预览卡带「深入」指针、章节逻辑列表。
**Must avoid:** 预览卡写满机制（那是档案的活）；一段引入两个新术语。
**Packet output:** content/overview.md 全部节。
**Self-check:** 预览卡 坑/招 与档案卡症状不得同文（机器查相似度）；每张卡的「招」必须含一个具体细节。
